The `/usr/bin/python3` and `/usr/bin/swift` shims failed because they invoke `xcrun`, which is unavailable inside App Sandbox. The implementation rejects those paths. Direct Xcode interpreters passed, with an explicit macOS SDK for Swift. Homebrew Python at `/opt/homebrew/bin/python3` was denied by the sandbox on this Mac; terminal executability alone does not establish plugin compatibility. Command Line Tools and other custom toolchain installations need their own signed-app checks.
